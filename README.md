# Coulomb's Law Inquiry Lab

Inquiry-based electrostatics simulation for helping students discover and practice Coulomb's law with teacher-facing presets.

## Included setups

- Two-charge force lab for attraction, repulsion, and inverse-square reasoning
- Three-charge line setup for superposition on one axis
- 2D triangle setup for component-based net-force problems
- U-235 fission scale demo for extreme small-distance force
- Equilibrium bridge for suspended-sphere style force-balance questions

## Notes

- Dark mode defaults to the Thinking Experiment visual system.
- Light mode follows the Half-Atwood style language and can be toggled from the hero.
- Presets and prompts were aligned to the uploaded Unit 7 notes and homework documents.
